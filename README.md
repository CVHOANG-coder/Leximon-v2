# Leximon

A clean Flutter mobile app foundation named Leximon and inspired by the structure and visual language of WaifuAI.

## Included

- Dark-first Material 3 theme with a purple accent palette.
- Feature-first folders for core, data, shared state, and presentation.
- Riverpod for state and GoRouter for navigation.
- Four-tab shell: Discover, For you, Messages, and Profile.
- Mock character data, favorites interaction, character detail sheet, and create-flow placeholder.

## Run

```bash
flutter pub get
flutter run
```

For iOS CocoaPods workflows:

```bash
flutter pub get
cd ios
pod install
cd ..
```

Backend, Firebase, ads, and paid-service integrations are intentionally not included yet.
