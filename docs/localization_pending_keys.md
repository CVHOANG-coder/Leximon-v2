# Pending localization keys

Danh sách này chỉ là inventory để chuyển các chuỗi UI còn hard-code sang localization.
Chưa yêu cầu dịch hoặc nối key vào màn hình. Các placeholder động dùng cú pháp `{name}`.

## Key chung nên tái sử dụng

- `back`, `continue`, `retry`, `cancel`, `save`, `close`, `exit`, `skip`
- `loading`, `check`, `next`, `done`, `completed`, `correct`, `incorrect`
- `yourAnswer`, `correctAnswer`, `attention`, `listenAgain`
- `levelBeginner`, `levelIntermediate`, `levelAdvanced`
- `skillListening`, `skillVocabulary`, `skillGrammar`
